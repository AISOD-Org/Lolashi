# Project Summary
The project is an online platform dedicated to promoting and selling the book "Illuminati One World Government Agenda Will Fail" by Sam Tiliindje. It offers a visually engaging interface with a religious theme, incorporating secure payment processing through Stripe and email notifications for order confirmations. The platform's goal is to disseminate the author's message effectively while enhancing user engagement through various interactive features.

# Project Module Description
- **Backend**: Handles API requests, payment processing, and database interactions.
- **Frontend**: User interface for browsing the book, placing orders, and managing subscriptions.
- **Payment Integration**: Enables secure online payments via Stripe.
- **Email Notifications**: Sends order confirmations and updates through SendGrid.
- **Newsletter Subscription**: Allows users to sign up for updates.
- **Testimonials Section**: Displays reader testimonials to enhance credibility.
- **FAQ Page**: Provides answers to common questions for user assistance.
- **Back-to-Top Button**: Improves navigation on lengthy pages.
- **Custom 404 Page**: Friendly error page featuring a relevant scripture quote.
- **Social Share Buttons**: Allows users to share the book on social media.

# File Description Inventory
- **backend/**
  - `main.py`: Entry point for the backend application.
  - `routers/`: Contains API route definitions for payment, authentication, etc.
  - `services/`: Contains business logic, including payment processing and email notifications.
  - `core/`: Contains core functionalities such as database configuration and authentication.
  - `data_models/`: JSON files representing data structures.
  
- **frontend/**
  - `src/`: Contains the main source code for the frontend application.
  - `components/`: Reusable UI components like buttons and forms.
  - `pages/`: Page components for different routes, including the FAQ and NotFound pages.
  - `App.tsx`: Main application component for routing and layout.

# Technology Stack
- **Backend**: FastAPI, SQLAlchemy, Stripe, SendGrid
- **Frontend**: React, Vite, Tailwind CSS, TypeScript
- **Database**: PostgreSQL (via SQLAlchemy)

# Usage
1. **Install dependencies**:
   - For the backend, navigate to `app/backend` and run:
     ```
     pip install -r requirements.txt
     ```
   - For the frontend, navigate to `app/frontend` and run:
     ```
     pnpm install
     ```
2. **Build the project**:
   - In the `app/frontend` directory, run:
     ```
     pnpm run build
     ```
3. **Run the application**:
   - Start the backend server and frontend application as per your setup instructions.
