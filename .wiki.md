# Project Summary
The project is focused on creating an online platform for purchasing the book "Illuminati One World Government Agenda Will Fail" by Sam Tiliindje. It integrates a payment gateway (Stripe) for secure transactions and implements email notifications for order confirmations. The website is designed to reflect a religious and lively aesthetic, enhancing user experience while promoting the author's message.

# Project Module Description
- **Backend**: Handles API requests, payment processing, and database interactions.
- **Frontend**: User interface for browsing the book, placing orders, and managing subscriptions.
- **Payment Integration**: Manages online payments through Stripe.
- **Email Notifications**: Sends order confirmations via SendGrid.
- **Newsletter Subscription**: Allows users to subscribe for updates.

# File Description Inventory
- **backend/**
  - `main.py`: Entry point for the backend application.
  - `routers/`: Contains API route definitions for payment, authentication, etc.
  - `services/`: Contains business logic, including payment processing and email notifications.
  - `core/`: Contains core functionalities such as database configuration and authentication.
  - `data_models/`: JSON files representing data structures.
  
- **frontend/**
  - `src/`: Contains the main source code for the frontend application.
  - `components/`: Reusable UI components like buttons and form inputs.
  - `pages/`: Page components for different routes.
  - `App.tsx`: Main application component for routing and layout.

# Technology Stack
- **Backend**: FastAPI, SQLAlchemy, Stripe, SendGrid
- **Frontend**: React, Vite, Tailwind CSS, TypeScript
- **Database**: PostgreSQL (via SQLAlchemy)

# Usage
1. **Install dependencies**:
   - For the backend, navigate to `app/backend` and run:
     ```
     pip install -r requirements.txt
     ```
   - For the frontend, navigate to `app/frontend` and run:
     ```
     pnpm install
     ```
2. **Build the project**:
   - In the `app/frontend` directory, run:
     ```
     pnpm run build
     ```
3. **Run the application**:
   - Start the backend server and frontend application as per your setup instructions.
