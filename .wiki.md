# Project Summary
The project is an online platform designed to promote and sell the book "Illuminati One World Government Agenda Will Fail" by Sam Tiliindje. It features a visually appealing interface that reflects a religious theme, integrating secure payment processing through Stripe and email notifications for order confirmations. The platform aims to spread the author's message and engage users with additional features that enhance the overall experience.

# Project Module Description
- **Backend**: Manages API requests, payment processing, and database interactions.
- **Frontend**: Provides the user interface for browsing the book, placing orders, and managing subscriptions.
- **Payment Integration**: Facilitates secure online payments via Stripe.
- **Email Notifications**: Sends order confirmations and updates through SendGrid.
- **Newsletter Subscription**: Allows users to sign up for updates.
- **Testimonials Section**: Displays reader testimonials to boost credibility.
- **FAQ Page**: Answers common questions to assist users.
- **Book Excerpt Preview**: Offers a preview of selected chapters to entice potential buyers.
- **Back-to-Top Button**: Enhances navigation on long pages.
- **Custom 404 Page**: Provides a friendly error page with a relevant scripture quote.
- **Social Share Buttons**: Enables users to share the book on social media platforms.

# File Description Inventory
- **backend/**
  - `main.py`: Entry point for the backend application.
  - `routers/`: Contains API route definitions for payment, authentication, etc.
  - `services/`: Contains business logic, including payment processing and email notifications.
  - `core/`: Contains core functionalities such as database configuration and authentication.
  - `data_models/`: JSON files representing data structures.
  
- **frontend/**
  - `src/`: Contains the main source code for the frontend application.
  - `components/`: Reusable UI components like buttons, forms, and new features.
  - `pages/`: Page components for different routes, including the new FAQ and NotFound pages.
  - `App.tsx`: Main application component for routing and layout.

# Technology Stack
- **Backend**: FastAPI, SQLAlchemy, Stripe, SendGrid
- **Frontend**: React, Vite, Tailwind CSS, TypeScript
- **Database**: PostgreSQL (via SQLAlchemy)

# Usage
1. **Install dependencies**:
   - For the backend, navigate to `app/backend` and run:
     ```
     pip install -r requirements.txt
     ```
   - For the frontend, navigate to `app/frontend` and run:
     ```
     pnpm install
     ```
2. **Build the project**:
   - In the `app/frontend` directory, run:
     ```
     pnpm run build
     ```
3. **Run the application**:
   - Start the backend server and frontend application as per your setup instructions.
