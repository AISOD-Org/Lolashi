# Project Summary
The project is a dynamic website designed to promote and sell the book "Illuminati One World Government Agenda Will Fail" by Sam Tiliindje. It serves as an interactive platform that not only showcases the author's insights and spiritual messages but also facilitates direct purchases. Recent enhancements have improved user engagement through features like an admin dashboard, order tracking, and a newsletter signup.

# Project Module Description
- **Homepage**: Displays the book title, cover image, and a purchase button along with a newsletter signup section.
- **The Book**: Contains details about the book, including ISBN, publisher, and synopsis.
- **About Author**: Provides a biography of Sam Tiliindje, including previous works and social media links.
- **Order**: A checkout form for purchasing the book, now includes an order ID display after submission.
- **Track Order**: A new feature allowing users to track their order status by email or order ID.
- **Admin Dashboard**: Accessible at `/admin`, displays all orders with customer details and allows status updates for each order.
- **Contact**: A form for inquiries and communication with the author.
- **Terms & Conditions**: Legal information regarding the book's sale and distribution.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS
- **Animations**: Framer Motion
- **Build Tool**: Vite
- **Styling**: PostCSS, Tailwind CSS

# Usage
1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Build the application:
   ```bash
   pnpm run build
   ```
3. Run the application:
   ```bash
   pnpm run lint
   ```
